# Summary Report — Doc Intelligence Pipeline

This document describes the structure of the generated `.docx` summary report
produced by `pipeline.py actions`. The report is written to
`root/actions/summary_YYYYMMDD_HHMMSS.docx`.

## Report Sections

### 1. Title Page
- Document title: "Doc Intelligence Pipeline — Summary Report"
- Generated timestamp
- Pipeline version (from config.toml)

### 2. Collection Summary
- Total documents in manifest
- New documents since last report
- Total size of collected corpus
- Scan directories covered

### 3. Extraction Statistics
- Files successfully parsed
- Files failed (with reasons)
- Average document size (chars, words, paragraphs)
- Total corpus word count

### 4. Knowledge Findings

#### Hints Detected
- Count of imperative language instances
- Top 5 most frequent hint patterns
- Example snippets (up to 10)

#### Repetitive Words
- Top 20 recurring terms across the corpus
- Terms unique to single documents (potential jargon)

#### Layout Patterns
- Distribution: heading-heavy vs table-heavy vs image-heavy documents
- Outliers (unusually structured documents)

#### Reused Assets
- Images shared across 3+ documents (likely templates)
- Images shared across exactly 2 documents (potential duplicates)

#### Duplicate Candidates (SOFT FLAG)
- Pairs with similarity > 0.90
- Pairs with similarity 0.85–0.90 (borderline)
- **All flagged as**: "might be a small change — investigate"

### 5. Recommended Actions
- Documents to review (high duplicate similarity)
- Template images to standardize
- Terms to add to project glossary
- Documents needing structural cleanup

## Output Format

The `.docx` file is generated by `python-docx` with:
- Heading styles (Heading 1, Heading 2, Heading 3)
- Bullet lists for findings
- Tables for statistics
- Monospace font for file paths and code snippets

If `python-docx` is not installed, a plain-text version is printed to stdout
and saved as `root/actions/summary_YYYYMMDD_HHMMSS.txt`.
